# FitLog — Gym Companion & Workout Tracker

FitLog is a dark, no-nonsense gym companion web application designed to help fitness enthusiasts pick lifts, lock them into today's plan, and track their weekly progress with ease.

## Technologies Used
- **Next.js (App Router)** - For server-side rendering and fast page navigation
- **Tailwind CSS** - For modern, responsive styling and pixel-perfect design alignment
- **TypeScript** - For type-safe component development
- **Fetch API** - For pulling workout data directly from the backend endpoint

## Key Features
1. **Interactive Workout Library** - Browse a 12-workout library covering every major muscle group fetched dynamically from the API.
2. **Plan & Saved Management** - Easily add workouts to "Today's Plan" (with a 5-lift daily cap) or save them for later access.
3. **Live Metrics Summary** - Real-time calculation of total exercises, minutes, and calories based on your active plan.
4. **Sort & Filter Controls** - Re-sort your workout lists by duration, calories, or rating instantly.
5. **Interactive Workout Logging** - Mark individual exercises as completed, view detailed specifications, and receive instant toast notifications.
